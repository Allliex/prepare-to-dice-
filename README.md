# Кубы D&D — Android-приложение

Бросок кубов d4–d100 и монетки, две темы (Dark Souls и неон), работает без интернета.

## Где взять APK

Раздел **Releases** справа → **Кубы D&D** → файл **DnD-Dice.apk**.
Эту ссылку можно просто отправить другу.

## Как установить на телефон

1. Открой скачанный DnD-Dice.apk.
2. Если телефон спросит — разреши установку из этого источника (браузера или мессенджера).
3. Если появится предупреждение Play Защиты — нажми «Подробнее» → «Всё равно установить».

## Как обновить

Замени `app/src/main/assets/index.html` новой версией и увеличь `versionCode` в `app/build.gradle`.
Сборка запустится сама, через 3–5 минут новый APK появится в Releases.
